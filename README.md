## В коде представлены 4 молудя 

1. Модуль views с одной функцией main, необходимой для связи функций из модуля utils


2. Модуль utils с функциями: 
- file_reader_excel - Читает Excel файл и возвращает список словарей с данными.
- get_greeting - Возвращает приветствие в зависимости от времени суток
- process_cards - Обрабатывает данные по картам
- get_top_transactions - Возвращает топ-N транзакций по сумме платежа
- get_currency_rates - Получает курсы валют
- get_stock_prices - Получает цены акций с использованием Alpha Vantage 
- generate_report - Генерирует полный отчет в формате JSON


3. Модуль services необходимый для поиска по телефонным номерам, с функцией search_number


4. Модуль reports необходимый для сортировки трат по категориям, с функцией search_number и декоратором decorator_with_args


## Тестирование функций
